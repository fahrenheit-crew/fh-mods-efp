## Extras, Fixes and Patches for Fahrenheit

This mod is home to an assortment of optional, but highly recommended fixes and patches for the Final Fantasy X/X-2 HD Remasters.

It can be considered the [Fahrenheit](https://github.com/fahrenheit-crew/fahrenheit) analogue of the [USSEP](https://www.nexusmods.com/skyrimspecialedition/mods/266) for Skyrim 
- a set of foundational fixes for the game that fixes long-standing subtle issues, or commonly reimplemented basic functionality.

If your mod bundles a fix for some issue in the game, please consider removing it from your mod and submitting a pull request to integrate it to EFP instead,
as it will then be maintained and kept in sync with [Fahrenheit](https://github.com/fahrenheit-crew/fahrenheit) by the project developers themselves.
